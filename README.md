# 🏡 Семейный помощник по подбору жилья

Приватный сервис-помощник для многодетной семьи при покупке квартиры или дома —
с учётом гос. поддержки и финансового плана. Регион фокуса: **Иркутская область**
(с расширяемостью на всю РФ). Реализация по ТЗ v1.0.

> ⚠️ Сервис даёт **предварительный расчёт и подборку**, это **не** юридическая
> консультация. Все условия льгот, ставок и выплат обязательно проверяйте в банке,
> МФЦ, СФР или у юриста перед сделкой.

## Что умеет

- **Семья и бюджет** — состав семьи, доход, собственные средства, якорные адреса с весами (геокодирование через OSM/Nominatim).
- **Объекты** — ручной ввод вариантов жилья; по каждому — «паспорт объекта».
- **Импорт из объявления** (Этап 4) — букмарлет «🏡 В помощник» читает открытую страницу объявления (JSON-LD / OpenGraph) и открывает предзаполненную форму; либо ручная вставка ссылки/текста. Без бэкенда и без нарушения правил площадок: одна страница, инициированная пользователем.
- **Карта района** — Leaflet + OpenStreetMap: объект, радиус, якоря и слои инфраструктуры (школы, детсады, поликлиники, магазины, остановки, парки) через Overpass API.
- **Льготы** — обновляемая база знаний (федеральные + Иркутская область) с автоприменением к семье и объекту, чек-листами документов и предупреждениями (например, «только новостройка»).
- **Калькулятор цены** — итоговая цена с учётом маткапитала, субсидий и выплаты 450 000 ₽; сравнение 2–3 сценариев.
- **Финплан** — график платежей, долговая нагрузка, стресс-сценарии (рост ставки, падение дохода).
- **Риелторский чек-лист** — юридическая и техническая проверка (ЕГРН, коммуникации, статус земли; для Иркутска — сейсмика и подтопляемость).
- **Аренда vs ипотека**, **сравнение избранного**, **экспорт карточки в PDF** (печать браузера).

## Приватность

Данные о доходах и составе семьи **не покидают браузер** — хранятся в `localStorage`.
В сеть уходят только запросы карт (тайлы OSM) и инфраструктуры (Overpass) — с
координатами объекта, без персональных данных.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшн-сборка в dist/
npm run test     # юнит-тесты калькуляторов и движка льгот
```

## Деплой на GitHub Pages

В репозитории настроен автодеплой (`.github/workflows/deploy.yml`): при каждом push
в рабочую ветку GitHub Actions собирает проект и публикует на Pages.

**Один раз включить Pages:** в репозитории → **Settings → Pages → Build and deployment
→ Source: GitHub Actions**. После этого дождитесь зелёного workflow во вкладке **Actions** —
сайт будет доступен по адресу вида `https://<user>.github.io/<repo>/`.

Приложение клиентское: данные каждого посетителя остаются в его браузере, сервер отдаёт
только статику. Роутинг — на `HashRouter` (адреса вида `…/#/family`), чтобы прямые ссылки
и обновление страницы работали на Pages без 404.

## Обновление базы льгот

База льгот — это **данные, а не код** (условия меняются 1–2 раза в год):

- `src/data/benefits/federal.json` — федеральные меры
- `src/data/benefits/irkutsk.json` — региональные (Иркутская область)

У каждой записи есть поле `lastVerifiedAt`. Если проверка старше 3 месяцев —
в интерфейсе появляется бейдж «Проверка устарела». Сверять актуальность по
источникам: irkobl.ru, sfr.gov.ru, дом.рф, Госуслуги.

## Технологии

React + TypeScript + Vite, Tailwind CSS, React Router, Zustand (persist),
Leaflet / react-leaflet, Recharts. Без бэкенда — полностью клиентское приложение.

## Структура

```
src/
  lib/         # ядро: mortgage, priceCalc, financePlan, benefitsEngine, geo, overpass, format
  data/benefits/  # база знаний по льготам (JSON) + схема
  store/       # Zustand-сторы (family, properties) с персистом
  features/    # экраны: input, properties, map, benefits, calc, finance, checklist, compare
  components/  # UI-примитивы
```
